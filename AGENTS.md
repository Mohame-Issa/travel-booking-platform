# Instructions for AI coding tools

This is a 7-person university project. Before writing any code:

1. Read and follow **`AI_RULES.md`** in the repository root (folders, naming, errors, guards, shared services, safety rules).
2. Read `docs/requirements/Milestone_1_Work_Split.pdf` and build **only** the section of the person you are working for. If they have not told you their name, ask them.
3. Take exact business rules from the **Mandatory** sheet of `docs/requirements/Final_ SP1_Reviewed_Requirements.xlsx`.
